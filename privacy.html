ENC Updater: privacy policy

ENC Updater is a small private tool that runs on one computer. It keeps the Australian electronic navigational charts used by a navigation program up to date. It is not offered to the public.

What it reads

ENC Updater has read-only access to the one Gmail account it is set up for. It looks only for emails from the Australian Hydrographic Office about chart updates, and the files attached to them (chart permits and update reports).

What it does with it

It uses those emails to work out which chart updates are available. It saves their attachments, and a note of the charts loaded, on the computer it runs on.

It cannot send, delete or change any email.

Where it is kept

Only on that computer. Nothing is sent to any other computer or server. Nothing is shared with, or sold to, anyone. There is no advertising, analytics or tracking.

Google user data

ENC Updater's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time in the Google Account's third-party connections. Files saved on the computer stay there until they are deleted.

Changes

Any change to this policy will be shown on this page.
